# blind_collection_auction

**Blind box collection tracker/auction site**

Deployment
User accounts
Create data source of blind box collections with names and pictures
Users can friend other users
Users can track their collections
Search for blind boxes and add which items they already have (and in what quantities)
Can search through friends' collections and create trade proposals
Users can put up blind box items from their collection for sale in a live auction
Set a starting price, deadline when auction ends, upload photos/text description of product
Other users can place bids, which are seen live
Abuse prevent features (e.g. requiring minimum bid amount)
When auction deadline is reached, highest bidder wins, "money" changes hands, removed from auctioneers' collection

Optional: Set buyout price, if any bidder bids that amount they automatically win auction

LLM: HTML/CSS generation, limited JS codegen (start manually, use when stuck, especially for debugging)
